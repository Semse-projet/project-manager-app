# Plan — Durable signature dispatch checkpoint and safe reconciliation

**Spec:** `m1.4-signature-dispatch-outbox.spec.md` (`m1-4-signature-dispatch-outbox`)  
**Related:** #826  
**Status:** DRAFT — not a merge, deploy or production certification.

### Persistent model
New additive `SignatureDispatchOutbox` contains tenant/connection/provider/contract/idempotency, request fingerprint, optional externalRequestId and checkpoint status. Atomic unique reservation precedes any POST. `RESERVED → CREATED → SENT` transitions require compare-and-swap predicates.
### Failure analysis
A provider may succeed during a network timeout or before local checkpoint. The journal blocks *new send attempts*, and a privileged reconciler must retrieve matching external requests before any action. Never assume exactly-once delivery or retry blindly.
### Migration and operational scope
Use migration `20261008170000_signature_dispatch_outbox` and Prisma generate, real PostgreSQL concurrency testing, schema drift and migration history checks. Non-destructive forward-fix and hard OFF switch until recovery is certified.
### Observability
Track ambiguous queue age, pending reconciliation, duplicates, mismatched tenant reads, and statuses with provider correlation; redact payload/PII. Restrict operator actions via ADR-042.
