# SEMSE Mobile Docs

Este directorio aterriza la absorcion quirurgica de la app movil dentro del ecosistema `labsemse`.

## Objetivos

- Definir identidad y proposito por superficie.
- Separar demo visual de integracion canonica.
- Establecer el orden de cableado por dominio.
- Mantener trazabilidad entre UX movil, BFF web y API principal.

## Estructura

- `surfaces/`: identidad funcional por bloque de pantallas.
- `integration/`: planes de cableado y decisiones tecnicas.
