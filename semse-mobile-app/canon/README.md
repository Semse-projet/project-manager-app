# SEMSE Mobile Canon

Esta carpeta define el canon local de la app movil de `SEMSEproject`.

No reemplaza la constitucion soberana de la raiz:

- `/home/yoni/labsemse/constitution`
- `/home/yoni/labsemse/program`
- `/home/yoni/labsemse/vision`
- `/home/yoni/labsemse/agents`

Su funcion es aterrizar ese canon al frente movil para:

- definir identidad y proposito;
- fijar limites no negociables;
- mapear dominios y nodos;
- alinear la app movil con el ecosistema vivo;
- evitar integracion caotica.

## Precedencia

En caso de conflicto:

1. raiz `constitution/`
2. raiz `program/`
3. raiz `vision/`
4. `project-manager-app/docs/SOURCE_OF_TRUTH.md`
5. este bloque `semse-mobile-app/canon/`
